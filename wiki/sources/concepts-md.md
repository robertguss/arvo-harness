# Source: CONCEPTS.md

**Path:** `CONCEPTS.md`  
**Purpose:** Shared process glossary (entities, named processes, status
concepts). Glossary only — not a full product spec.

## Key takeaways

- **Session** owns product turns, JSONL, cancel, usage.
- **HEAD** is explicit tree pointer; tree navigator primary over bare rewind.
- **Cancel-as-fork**, **handoff**, **focus claim**, **turn-busy**.
- **Progressive attention** stack: hot / warm / cold; context firewall; dual
  view; attention evidence stream.
- **Agent tile** vs **workspace chrome** vs **ephemeral work pane** /
  **Arvo-owned pane registry** / **pane tools**.
