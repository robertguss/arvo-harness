# Source: CONTEXT.md

**Path:** `CONTEXT.md`  
**Purpose:** Normative product vocabulary and avoid-lists (names).

## Key takeaways

| Term | Meaning | Avoid |
| ---- | ------- | ----- |
| Arvo | Elixir product, binary, `~/.arvo/`, `.arvo/` | “the harness” in UX post-v0.1 for this product |
| Ore | Rust product twin | same for Ore |
| Harness | Shared machinery concept | CLI wrapper, framework |
| Tool | Model-invoked capability | function, command |
| Slash command | User-invoked from TUI | conflating with Tool |
| Plugin | Extension unit | extension, addon |
| Profile / base | Named plugin bundle; base always on | preset, mode, workspace |
| Provider | Model backend adapter | backend, model |
| Skill | SKILL.md package | prompt, snippet |
